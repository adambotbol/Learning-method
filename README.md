# Learning-method

Un site statique regroupant mes cinq matières du semestre EPFL, reconstruites à partir de mes notes et polycopiés — chapitre par chapitre, au fur et à mesure du semestre.

## Structure

- `index.html` — page d'accueil avec les cinq matières
- `courses/` — une page par matière (Algèbre I, Physique générale, Algèbre linéaire avancée, Analyse avancée, ICC)
- `assets/css/style.css` — système de design partagé
- `assets/js/main.js` — rendu des formules (KaTeX) et sommaire actif au scroll

## Aperçu local

```
python3 -m http.server 8000
```

puis ouvrir `http://localhost:8000`.
